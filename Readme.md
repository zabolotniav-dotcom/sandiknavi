**SandikNavi — это проект маленького бортового компьютера для Renault, Lada, Mitsubishi и много чего еще.**

**Основные возможности:**
Отображение инструкций от навигационных программ — следующий маневр, расстояние, время прибытия, название улицы

Отображение уведомлений от различных приложений (выбор приложений) с Android-смартфона или магнитолы

Отображение входящих звонков на смартфон

Часы и календарь

Отображение прогноза погоды с загрузкой через смартфон/магнитолу (OpenMeteo)

Русский язык

Вывод температуры двигателя по CAN

Вывод температуры вариатора по CAN

Вывод внешней температуры по CAN

Вывод оборотов по CAN

Вывод скорости по CAN

Вывод скорости по GPS

Вывод напряжения бортовой сети по CAN

Вывод угла поворота рулевого колеса (должен быть датчик!)

Вывод пробега

Вывод текушей скорости

Для некоторых плат поддерживается функция креномера

Поддержка пользовательских вариантов оформления главного экрана (скинов)

Возможность при наличии познаний в CAN добавлять новые параметры или поддержку других автомобилей

Возможность настраивать стартовое лого, загружая его со смартфона.

Данные можно получать не только через can-адаптер, но и просто купив хороший Bluetooth-сканер.

**Имеется поддержка следующих протоколов через elm327 ble:**

1: "SAE J1850 PWM 41.6 kbit/s";

2: "SAE J1850 VPW 10.4 kbit/s";

3: "ISO 9141-2";

4: "ISO 14230-4 KWP slow init";

5: "ISO 14230-4 KWP fast init";

6: "ISO 15765-4 CAN 11 bit 500 kbit/s";

7: "ISO 15765-4 CAN 29 bit 500 kbit/s";

8: "ISO 15765-4 CAN 11 bit 250 kbit/s";

9: "ISO 15765-4 CAN 29 bit 250 kbit/s";

всего 25 параметров, из которых можно одновременно вывести 3. Ограниченная поддержка custom pid от программы Torque в виде файлов csv. С минимальными правками такие файлы можно применять на SandikNavi.

Возможность удаленного управления платами без сенсорного дисплея, которые можно врезать в приборную панель

Пользовательские скины и протоколы для получения данных из авто, загружаемые со внутренней памяти устройства
